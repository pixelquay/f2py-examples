1. Understand Fortran INTENT Declarations in f2py

Unlike plain Fortran compilers where all subroutine parameters pass by mutable reference, f2py treats any parameter without an explicit INTENT as input-only (INTENT(IN)). Use INTENT(OUT) to return values to Python or INTENT(INOUT) with a numpy.ndarray buffer.
